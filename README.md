# Overview
This Firefox plugin adds Stylus support to the "Moodle annotate pdf" plugin. (Testes on Moodle 4.5 with Surface Pro 8 Stylus)<br><br>
**Features include**:
- automatically switch between 
  - dragging-tool with touch, 
  - your last active drawing tool when drawing with the pen and 
  - selecting-tool with the Pen eraser button.<br>
    (This tool counts as a drawing tool, but the pen-eraser switches to this tool only temporarily)
