# Overview
This Firefox plugin adds stylus support to the Moodle "annotate pdf" plugin. 
(Tested on Moodle 4.5 with Surface Pro 8 Stylus). Only activates when grading submissions (meaning urls that match: [...]/mod/assign/view.php?[...]action=grader[...])<br><br>
**Features include**:
- automatically switch between 
  - dragging-tool with touch, 
  - your last active drawing tool when drawing with the pen and 
  - selecting-tool with the Pen eraser button.<br>
    (This tool counts as a drawing tool, but the pen-eraser switches to this tool only temporarily)
  
- if touch/stylus input is registered, removes the "Draft annotations saved"-message that was spammed, (works for english and german)
